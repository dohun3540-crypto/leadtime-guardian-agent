# 질의응답 초안

## 정확도가 얼마인가요?
현재 공식 정확도는 NOT_MEASURED다. 실제 승인 Gold와 동일 입력의 적격 예측·분자/분모가 확보되기 전 수치를 말하지 않는다. 평가 근거 담당: 최유석.

## 테스트가 통과했는데 왜 완료가 아닌가요?
코드 회귀는 실제 Studio 실행·사람 원문 판단·Gold 승인·전체 연결 검증을 대신하지 않는다. 이번 커밋에 대한 테스트와 CI 역시 아직 미확인이다.

## C001 수치는 실측인가요?
이 준비본의 0→60과 60,500 KRW는 첨부 통합 문서의 수락 조건이다. 현재 연결된 신규 실행 증거로 확인한 값이 아니다.

## 식별자가 충돌하면 어떻게 하나요?
PO999를 PO1로 추정 수정하지 않고 검토·차단하는 것이 요구 조건이다. 실제 구현 결과는 동일 사례 입력/출력으로 검증해야 한다.

## 이번에 Studio를 실행하거나 수정했나요?
아니다. 신규 유료 실행·설정 편집·삭제를 하지 않았다. 화면 및 Native 기록 확인은 미완료다.

## 누가 답변하나요?
총괄 구도훈, 계산 윤현준, 원문·Gold 판단 김민주, 평가·Git CI 최유석. 이 파일은 팀 승인된 답변이 아닌 초안이다.
