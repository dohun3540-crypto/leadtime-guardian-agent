“발주서, 납기변경 통보, 견적서를 함께 읽어 납기 위험과 추가 조달 필요성을 검토하는 흐름을 설명하겠습니다. 지금은 정적 설명이며 신규 Live 실행 결과가 아닙니다.”

“먼저 세 문서가 같은 사례인지, 원본 파일과 발주·입고 식별자가 일치하는지 확인합니다. AI 워크플로우와 설정 버전, 운영 Job을 기록해 다른 실행이 섞이지 않게 합니다.”

“정규화된 결과를 Python 계산 입력과 연결합니다. C001의 검증 목표는 변경 전후 부족량과 견적을 근거까지 추적하는 것입니다. 아직 연결된 실행 증거를 확보하지 못했으므로 기대 수치를 실제 성과로 제시하지 않겠습니다.”

## 1:40~2:10 안전 차단

## 2:10~2:40 한계와 마무리
“코드 시험 통과와 사람 승인 Gold, 실제 추출 정확도는 다른 검증입니다. 승인 근거와 적격 평가가 없는 정확도는 미측정으로 남깁니다.”
